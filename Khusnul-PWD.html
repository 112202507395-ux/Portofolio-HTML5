A. Profil Saya

Halo! Nama saya Khusnul Khotimah, mahasiswi aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro. Selama menjalani perkuliahan di jurusan ini, saya memiliki ketertarikan yang cukup besar pada bidang pengembangan web, analisis alur sistem, dan pengelolaan basis data. Bagi saya, mempelajari teknologi bukan sekadar soal menulis kode, melainkan bagaimana kita bisa merancang sebuah sistem yang dapat membantu menyelesaikan masalah serta mempermudah pekerjaan sehari-hari secara efisien.

Halaman web portofolio ini saya susun menggunakan struktur HTML dasar sebagai bentuk dokumentasi sekaligus pemenuhan tugas untuk mata kuliah Pemrograman Web. Melalui pengerjaan tugas ini, saya belajar memahami fungsi dari berbagai tag HTML untuk menyusun tata letak halaman yang terstruktur dan mudah dibaca. Proses ini menjadi langkah awal yang penting bagi saya untuk memperkuat pemahaman dasar sebelum nantinya melangkah ke tahap pengembangan web yang lebih kompleks.
